# pnet（模拟网络配置环境）的安装

1. 安装好pnet之后点击pnet\.vmx（如果没有后缀，点击上方查看，点击显示文件拓展名），然后选择以vmware的方式打开，随后会出现在vmware中，然后点击开启此虚拟机。

2. 打开之后会显示访问的ip地址

3. 在浏览器上访问ip地址，登录界面会有用户名和密码，控制台有默认控制台（更便捷）和html控制台（兼容性更强），我们选择默认控制台。

4. 进入后点击设置，将默认语言改为中文（可能没有效果），然后点击Fix Permission（这个是用来修复权限的），然后将Docker Wireshark Only勾选，这个是用来抓包的。
